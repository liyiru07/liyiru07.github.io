选题

TOPIC

选题：《小王子》

《小王子》是安托万·德·圣埃克苏佩里创作的经典童话。故事以飞行员沙漠遇险为开端，讲述小王子离开 B612 星球，游历多个星球，遇见形形色色的大人，最终在地球领悟爱的真谛。

作品探讨爱、孤独、责任、驯服，适合做视觉解说视频，画面意象丰富，水彩插画风格适配视频制作，主题有深度，容易引发观众共鸣。

经典童话 爱与责任 孤独与驯服 水彩插画 视觉解说 共鸣度高
"你在你的玫瑰花身上耗费的时间，使得你的玫瑰花变得如此重要。"

03 / 08

文案

SCRIPT

解说词全文

共八段，与八幅画面对应；配音时长约 4～5 分钟，字幕与画面同步。

画面一

故事从一个迫降在撒哈拉沙漠的飞行员开始。在他飞机破损的孤独时刻，一个奇怪的小男孩出现在他面前，这个男孩，就是小王子。

画面二

小王子来自一个很小的星球，那里有三座火山，还有一朵骄傲的玫瑰。小王子每天给玫瑰浇水、挡风。可玫瑰的口是心非，总是让小王子感到困惑和伤心。于是他决定离开，去看看外面的世界。

画面三

小王子拜访了两颗小行星。一颗星球上住着国王，他统治着空无一人的世界；另一颗星球上住着虚荣的人，一心等着别人崇拜他。小王子无法理解这些大人的想法。

画面四

第三颗星球上住着一个酒鬼，他喝酒是为了忘记喝酒的羞愧。第四颗星球上住着一个商人，他忙着数星星，却对星星毫无用处。小王子越来越困惑：大人们到底在忙什么？

画面五

第五颗星球上住着一个点灯人。他的星球转得太快了，每一分钟就要点一次灯。但是他却从不偷懒。小王子觉得：这个人虽然荒唐，但他的工作是有意义的——因为他点亮的，是一盏灯，而不是一个数字。第六颗星球上住着一位地理学家，他记录永恒的山川海洋，却从未离开过书桌。他告诉小王子："花朵是短暂的。"

画面六

在地球上，小王子遇见了一只狐狸。狐狸告诉他："驯服，就是建立联系。你对我来说，只是一个普通的小男孩；我对你来说，也只是一只普通的狐狸。但如果你驯服了我，我们就会彼此需要。你将成为我世界上唯一的人，我也将成为你世界上唯一的狐狸。"

画面七

后来，小王子走进了一座玫瑰园，看到了五千朵一模一样的玫瑰。他哭了，因为他以为他的玫瑰是宇宙中独一无二的。小王子终于明白：他的玫瑰之所以独一无二，不是因为她长得特别，而是因为他爱她。

画面八

《小王子》告诉我们：真正重要的东西，用眼睛是看不见的。如果你遇见一个有着金色头发、不肯回答问题的男孩，请一定要写信告诉我：他回来了。

方法

METHOD

五步创作流程

1

内容构思

阅读《小王子》原著，梳理故事主线，筛选 8 个核心情节片段，撰写解说词。

2

图像生成

使用 AI 绘图，输入提示词，统一水彩插画风格，生成 8 张配套画面。

3

视频制作

将图片按顺序排列，导入剪辑软件，添加 AI 配音、字幕，合成 4-5 分钟解说视频。

4

网页制作

用 WorkBuddy 生成带标签切换动画的动态网页，把选题、策划、文案、素材、方法、工具、视频、总结全部放进页面。

5

部署上线

本地预览网页，检查交互效果，上传至 GitHub 仓库，开启 GitHub Pages 发布网页。
